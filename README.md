# Piano Note Trainer

A browser piano teacher focused on learning to **read music**. It shows notes on the staff, listens
through your **microphone**, and checks what you play on your piano.

**Live:** https://herman-knol.github.io/web-piano/

## Note trainer

- One note at a time on the treble or bass clef (or both, mixed)
- Four levels: C position → whole staff → ledger lines → sharps & flats
- Play the note on your piano (mic) or click the on-screen keyboard
- Wrong answer? The note you played appears in red on the staff, so you can see the difference;
  after two misses it tells you the answer
- Adaptive: new, slow and often-missed notes come up more often
- Per-note mastery map, streak, accuracy, response time, and a 60-second challenge with a saved best

## Run it

```bash
npm install
npm run dev
```

Open the printed URL in Chrome, Edge or Firefox, press **Start listening**, and allow microphone access.

- Sheet music rendering with a following cursor (OpenSheetMusicDisplay)
- Mic pitch detection (pitchy / McLeod pitch method); detects single notes, including repeated ones
- Wait mode: the score waits until you play the note under the cursor
- Right or left hand practice; on chords it checks the top note (RH) or bottom note (LH)
- "Accept any octave" for mics that mishear the octave; optional note-name hints
- Built-in public-domain songs, plus **open your own MusicXML** (`.musicxml`, `.xml`, `.mxl`)
- Best accuracy per song saved in the browser

## Adding songs

Copyrighted songs (for example Coldplay's "All My Love") can't be bundled in this repo.
Get a MusicXML file you're allowed to use, from a sheet music store, MuseScore ("Export → MusicXML"),
or your own transcription, and load it with **Open your own MusicXML…**.

Built-in songs are generated by `node scripts/make-songs.mjs` into `public/songs/`.
